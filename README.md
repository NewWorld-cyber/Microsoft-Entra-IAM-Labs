
# Microsoft Entra ID — IAM & Identity Governance Portfolio

## About This Project

I'm an IT professional with a CompTIA Security+ certification, building hands-on experience in Identity and Access Management (IAM) and Identity Governance.

I created this Microsoft Entra ID lab environment to practice real-world identity security tasks and better understand how organizations manage user access, enforce security controls, and support compliance requirements.

## Labs Completed

**Lab 1 — User Provisioning & Security Groups**
- Created and managed test users.
- Organized users into department security groups.

**Lab 2 — Employee Offboarding**
- Disabled a test employee account.
- Revoked authentication sessions.
- Verified changes through audit logs.

**Lab 3 — MFA & Authentication**
- Investigated multifactor authentication.
- Reviewed successful and failed sign-in events.

**Lab 4 — Role-Based Access Control**
- Assigned and removed administrator permissions.
- Tested least-privilege controls.
- Reviewed role-management audit logs.

**Lab 5 — Access Reviews & Compliance**
- Reviewed department group memberships.
- Documented simulated access-retention decisions.
- Identified audit and approval limitations.
